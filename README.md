# skAIld marketplace

Claude Code plugin marketplace for **skAIld** — the disciplined plan → build → ship loop for Claude Code.

## Install

```
/plugin marketplace add drophit/skaild-marketplace
/plugin install skaild@skaild
```

One plugin, one install. skAIld is a single Claude Code plugin — slash commands you invoke (`/skaild:<skill>`), or that Claude reaches for on its own.

## What's inside

The whole loop, in one install:

| Area | Workflows |
|---|---|
| **Foundation** | session-start banner + workflow menu, the Karpathy guidelines, auto-changelog from your commits |
| **Plan** | `/skaild:quick-plan`, `/skaild:start-planning` |
| **Build** | `/skaild:start-coding`, `/skaild:serve-worktree`, `/skaild:review-pr`, `/skaild:team-review`, `/skaild:create-pr`, `/skaild:merge-approved` |
| **Ship** | `/skaild:pre-deploy`, `/skaild:light-deploy`, `/skaild:hotfix`, `/skaild:handoff`, `/skaild:close-session` |

The plugin auto-installs its dependencies (`superpowers`, `commit-commands`) on install.

## Access

skAIld is delivered from a private repo; access is granted on subscription at **[skaild.com](https://skaild.com/advanced)**.
